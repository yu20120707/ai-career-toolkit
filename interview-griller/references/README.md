# Interview Reference Question Bank

This directory is an optional reference layer for `interview-griller`. It is not a replacement for the submitted resume, target JD, claim map, or factual interview feedback.

## Categories

- `question-bank/real-interviews/` — user-provided real interview question collections. Use these as high-priority examples of question style and topic frequency, not as universal hiring rules.
- `question-bank/fundamentals/` — C++, Linux, operating systems, networking, MySQL, and concurrency notes. Use the relevant topic as background for textbook questions and follow-ups; do not load every file for every session.

See [`question-bank/manifest.json`](question-bank/manifest.json) for topic labels and source boundaries.

## Selection policy

1. Prioritize the actual submitted artifact, JD, active claims, project deep-dive note, and prior weak points.
2. Use real-interview material next when the user asks for company-style or general interview drilling.
3. Use fundamentals only for the selected topic; connect the answer back to the user's project or role when possible.
4. Ask one question at a time. Do not dump an article or reveal a complete standard answer before the user attempts the question.
5. Treat the materials as user-provided study references. If a statement is version-sensitive, disputed, or inconsistent with the user's code, mark it for verification instead of presenting it as certain fact.

## Provenance and privacy

The files were copied from the user's local study materials on 2026-08-10. They may contain third-party excerpts, company names, or other identifying details. Review attribution, copyright, and personal-data exposure before publishing this repository or distributing the reference files.
